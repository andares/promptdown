低 UI 提示词输入框

核心只负责文本、光标与高亮；边框、背景、工具栏、发送按钮全部由宿主决定。 下面是三种“直接嵌入”的姿势，以及一层用它的 API 搭出来的基础 UI。

低 UI · 聊天输入

组件不画边框、不抢字体；输入变化经 pd-input 事件交给宿主。

（这里镜像当前值）

低 UI · 表单 / 侧栏

light DOM 模式（shadow="false"）：宿主可以直接用 .pd-key 等 class 上色。

没有工具栏、没有状态栏；只有一个能精确编辑文本的输入区。

低 UI · 继承宿主排版

不传任何样式时，字体、字号、颜色全部继承。下面是 17px 衬线正文里的编辑器。

主题是 CSS 变量，不是 API

token 默认由 currentColor 派生，任何底色都不突兀；需要品牌色时覆盖变量即可。

pd-editor {
  --pd-font-size: 14px;
  --pd-line-height: 1.6;
  --pd-token-key: #2f6f63;
  --pd-token-ref: #a94f27;
  --pd-placeholder-opacity: .45;
  --pd-focus-ring: none;
}
键名: - 序列:引用 `行内代码`//!pd

基础 UI 层：用同一套 API 搭一个工具栏

格式化、双向转换、语言切换、复制、清空、计数——全部是宿主代码；核心没有多出一行 UI。

各框架怎么用

自定义元素是共同底座；React 有官方薄包装，其余框架直接绑定 property / 事件即可。

React

import { PdEditor } from "@andares/pdeditor/react";

<PdEditor
  defaultValue="任务: 写一个防抖搜索"
  onValueChange={setValue}
/>

Preact

import "@andares/pdeditor/element/auto";

<pd-editor
  ref={ref}
  onInput={() => setValue(ref.current.value)}
/>

Solid

import "@andares/pdeditor/element/auto";

<pd-editor
  ref={el}
  prop:value={value()}
  on:pd-input={e => setValue(e.detail.value)}
/>

Vue 3

// vite.config.ts
vue({ template: { compilerOptions: {
  isCustomElement: t => t === "pd-editor"
} } })

<pd-editor :value="value"
  @pd-input="value = $event.detail.value" />

Svelte

import "@andares/pdeditor/element/auto";

<pd-editor bind:this={el}
  on:pd-input={e => value = e.detail.value} />

原生 / CDN

<script type="module">
  import "@andares/pdeditor/element/auto";
</script>

<pd-editor language="pd"
  placeholder="直接写…"></pd-editor>
