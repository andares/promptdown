# promptdown 语法速查

极简标记语言：兼容 markdown 风格，可 PD ↔ JSON 双向转换（`pdtransform`）。**完整规范见 `../../docs/SPEC.md`（唯一事实来源），本文件与 SPEC 冲突时以 SPEC 为准。**

> ✍️ 需要**写**提示词结构（而不是 markdown）？用作者版 skill：`../pd-author/SKILL.md`（触发词：写提示词/组织提示词/结构化提示词）。

## 行类型

| 行 | 语义 |
| --- | --- |
| `//!pd <name>` | 段标记（可省略）：声明 pd 内容开始；多段混排实现引用。无段标记的纯 pd 文本/文件可省略 |
| `//!pd`（裸） | 匿名段：只能 `%序号` 访问，不自动赋文件名 |
| `---` | 分隔线：块边界，指针回根（清掉之前所有父级） |
| `key:` | 裸键值：严格判定——键名不以空白结尾、冒号后跟空白或行尾（`a : b`、`a:b` 不是键值）；仅第一个冒号分隔键和值；在根对象创建键，不找爸爸，独立成父亲 |
| `- key:` | 带 `-` 键值：同裸键值的严格判定；按缩进找爸爸；找不到爸爸又是顶层 → 进 Subject |
| `- content` / `content` | 内容行：按缩进找爸爸，压入该块 Info 数组 |
| ` :refname ` / ` :%序号 ` | 引用：前后必须带空格，冒号后紧贴引用名；`%N` 为序号引用（匿名段也可引用）；编译期内联展开（``` 围栏内与 `` ` `` 行内代码内不展开） |
| `:-` / `：-` | 普通冒号标记：整行不识别键值，标记本身也不是引用；不影响后续引用 |
| `` `代码` `` | 行内代码整体字串：内部冒号/全角冒号/`-` 不参与键值/序列/转义/引用判定；不支持换行（未闭合即失效）。⚠️ helix（tree-sitter）无整体漂色、未闭合行按非键值显示（降级，语义仍以本规范为准） |

## 核心规则

1. **折叠**：键内只有单条字串（同行内容、无续行、无子键）→ `"key": "value"`；多行或混排 → `"key": { "Info1": [...] }`
2. **Info**：无 key 内容 → 默认键 `Info`（数组）；连续无 key 压入同一数组；中间出现键值分隔 → 编号自增（Info1 → Info2）；编号每层独立
3. **Subject**：顶层匿名对象根叫 Subject1/Subject2...（无 key 内容出现在根层级时）
4. **找爸爸**：裸键值行不找爸爸（根创建）；带 `-` 键值行与内容行按缩进找爸爸；`- words` 与 `- name:` 同缩进 → 平级
5. **空行无视**：没有 `---` 时空多少行都继续找爸爸
6. **语法错误**：顶层 `-` 不允许缩进
7. **代码块**：` ```lang ` 围栏 → `CodeN` 对象（`lang` 可空、`body` 为整个代码文本含换行）；只能归顶层键/Subject，打断 Info 段；围栏内不切段（`//!pd` 行不算段标记）、不展开引用、不参与格式化
8. 内联 markdown（`**粗体**`、`` `代码` ``）保留原文；行内代码段内冒号全豁免（键值/转义/引用判定均跳过）
9. 数组元素一行一个，无逗号分隔
10. **首个冒号（严格键值）**：键名不以空白结尾、冒号后跟空白或行尾（`a : b`、`a:b` 不是键值）；每行只有第一个冒号可作键值分隔符；右值中的后续冒号不会再开启键值，只有前后带空格的 ` :refname ` 仍按引用规则展开
11. **普通冒号标记**：行内只要出现 `:-` 或 `：-`，整行不识别任何键值；这两个字符原样作为正文，但后续合法引用仍展开

## 多段寻址（section）

- **序号模式**：全局 1-based 序号，必须以 `%` 开头——`%1` = 第 1 个 section；越界报错
- **字符模式**：`//!pd <name>` 的 name；**命名是数字也算字符**（`//!pd 1` → 命名 `1`）
- **`%` 转义**：命名首字符是 `%` → 存储名加倍为 `%%`（`%%` 开头 → `%%%`）；寻址字符模式直接与存储名比较
- **隐式段**：无 `//!pd` 的文件 = 一个段，段名 = 文件主名（去扩展名）；裸 `//!pd` 匿名段只能 `%N`
- **跨文件重名（pdcompile）**：先到先得，后出现的同名段自动匿名

## 引用（编译期内联展开）

- 引用名是冒号后紧贴、到下一个空白前的非空白字符序列（UTF-8，支持中文如 ` :基础设定 `）；唯一限制：不能以 `-` 开头，因为 `:-` 保留为普通冒号标记
- 引用的内容是纯文字 → 内联嵌入（保留前后空格）：`msg: say :base please`
- 引用的内容带语法标记 → 独立成行：按 `:refname` 位置前后断开全部转为 `-` 项，被引用段作为块嵌入
- 循环引用（含 `:%序号` 与命名指向同一段）→ 静默擦掉 `:refname`，不报错；嵌套上限 32 层
- 解析必须指定段（多段时）：段名或 `%序号`；``` 围栏内与行内代码内的 `:xxx` 不识别为引用

## 范例

```pd
name1:
- some
- name2: other words
- name3:
  - more
  - words
words
```

```json
{
  "name1": {
    "Info1": ["some"],
    "name2": "other words",
    "name3": { "Info1": ["more", "words"] },
    "Info2": ["words"]
  }
}
```

## 转 JSON

- CLI：`pdtransform <file> [段名|%序号]`（自动识别 pd/json 双向转换；多段按段名或 `%序号` 选段，裸数字是字符模式）
- `pdcompile <段名|%序号> <file>...`：多段编译为单份完整 pd（跨文件合并段列表、引用内联展开、统一 format）
- 规则：解析行类型 → 块栈按缩进找爸爸 → 键值单条折叠 → Info/Subject 编号 → 引用内联展开
- JSON→pd 反向（`pdtransform 文件.json`）：空行规则已移入 format（顶层带子域键值后空一行）；`SubjectN` 匿名块还原为裸文本/代码块（前补 `---`）；内容项第一个冒号转义（`a: b` → `a:- b`、`a：b` → `a：-b`，行内代码内不转，已含 `:-` 不再转）；标量转文本、结构性条目丢弃（逐条黄字警告）
